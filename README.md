# boxTup

A web application for visualizing 3D bin packing algorithms. It uses a C# algorithm compiled to WebAssembly to calculate item placement and React with Three.js to render the results in an interactive 3D scene.

## Tech Stack
- React + Vite + Javascript
- Zustand for state management
- Three.js / React Three Fiber for 3D visualization
- C# / WebAssembly for packing calculations
